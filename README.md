# Cloudflare 적용건
## 내용 수정은 Pages CMS에서 (추천)
1. https://app.pagescms.org 접속 → GitHub로 로그인
2. 처음 한 번: GitHub App 설치 → 이 저장소 선택 (비공개 저장소도 OK)
3. 저장소 열기 → 왼쪽 메뉴
   - **홈페이지 내용**: 채널 · 인기 영상 · 여행 가이드 · 추천템 추가/삭제/순서 변경, 사진 업로드
   - **사이트 문구 · 검색 설정**: 제목, 소개 문구, 검색 제목/소개문
4. 저장(Save) → GitHub에 자동 커밋 → 1~2분 뒤 사이트 반영

- 잠깐 빼두고 싶은 항목은 지우지 말고 **'사이트에서 숨기기'** 체크
- 사진은 폼에서 바로 업로드하면 `images/` 폴더에 저장됨 (파일명은 영어 소문자 + 숫자 추천)

## 직접 수정할 때
- 항목: `content.json` / 문구·검색 설정: `texts.json`
- 형식이 깨지면 Netlify가 배포를 멈추고 이전 사이트를 그대로 유지합니다
